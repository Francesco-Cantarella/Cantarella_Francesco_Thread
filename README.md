# Cantarella_Francesco_Thread - Produzione racetta da tenis
## 1. Autore
**Francesco Cantarella**
## 2) Descrizione del progetto
Questo progetto Java simula la **produzione di racchette da tenis** utilizzando i **tread**.  
ogni tread rapresenta una fase della produzione:
- Un thread costruisce il telaio della racchetta  
- Un altro thread si occupa di montare e sistemare le corde

## 3) Contenuto della repsitory
- src/: codice Java con commenti Javadoc  
     - ProduzioneRacchette.java, Telaio.java e Corde.java
- uml
- README.md: 
- javadoc.zip

## 4) Funzionamento del programma
Il programma avvia due tread:
1. telaio simula la fase di creazione del telaio
2. corde simula la fase di  incordatura
